CONNECTNET - ENTREGA 3

1. Extraia o ZIP em uma pasta separada do projeto antigo.
2. Abra a pasta no VS Code.
3. Confira se o Node.js 22 ou 24 está instalado.
4. Duplique .env.example e renomeie a cópia para .env.
   Mantenha a senha de exemplo entre aspas: SEED_PASSWORD="ConnectNet#2026".
5. Abra o terminal na pasta que contém package.json.
6. Execute npm ci e, em seguida, npm start.
7. Abra http://127.0.0.1:3000/login.html.
8. Para testar como administrador: admin@connectnet.local
   Senha de demonstração: ConnectNet#2026

O modo demo usa dados fictícios e reinicia os exemplos ao reiniciar o servidor.
